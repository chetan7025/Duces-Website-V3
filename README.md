## Setup cost estimator
The estimator collects jurisdiction, package, licence duration, activity count, shareholders, visa requirements and optional support services. It sends the selected requirements to the single contact form.

Displayed starting package references:
- AED 4,888 — licence package without visa
- AED 10,800 — licence package with one visa

These are DUCES package starting references, not live authority tariffs or all-inclusive quotations. Mainland, Offshore, multi-year terms, additional visas and optional services require a tailored quotation. Confirm current package pricing, inclusions, authority fees, VAT and additional charges in writing before accepting an order or payment.
